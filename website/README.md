# אתר לפסיכותרפיסטית

אתר תדמית סטטי בעברית (RTL), מותאם למובייל, ללא צורך בשרת או בהתקנות.

## קבצים
- `index.html` – כל התוכן של האתר
- `styles.css` – עיצוב (הצבעים והגופנים מוגדרים בראש הקובץ תחת `:root`)
- `script.js` – תפריט מובייל, טופס שנשלח לוואטסאפ, אנימציות

## מה צריך להחליף
חפשו בקובץ `index.html` את הטקסטים שבסוגריים מרובעים `[...]` והחליפו בפרטים אמיתיים:
- `[שם המטפלת]`, השכלה, הסמכות, שנות ניסיון, עיר, מחיר פגישה
- טלפון `050-000-0000` / `972500000000` ואימייל `name@example.com`
  (גם ב-`script.js` במשתנה `WHATSAPP_NUMBER`)
- תמונה: שימו קובץ ב-`images/profile.jpg` והחליפו את ה-`photo-placeholder` בתגית ה-`<img>` שמופיעה בהערה

## צפייה מקומית
פשוט לפתוח את `index.html` בדפדפן.

## העלאה לאוויר (חינם)
- **Netlify**: לגרור את תיקיית `website` ל-https://app.netlify.com/drop
- **GitHub Pages**: Settings → Pages, ולבחור את הענף והתיקייה
